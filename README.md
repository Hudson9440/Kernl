# Kernl
Kernl is the central hub for all calendars, to-do lists, and productivity tools you will ever need.


About the Project

Kernl is desighhned to be a sleak simple wellrounded hub of everything you need to remain productive and organized. This is desighned to remove the clutter of 5 seprate apps running at once to remain organized but instead be one app that does it all. I wanted to design this inorder to keep myself organized aswell as help others do the same.


Features

1. Sleak navagation bar to build on top of the future including a a home page, calendar and todo list page.

2. The Todo list is a simple and non invasive event racker to keep your thoughts in order. It includes the name of the task the state of the task (complete or incomplete) and the priority of the task.

3. The todo list also feature a modal to prompt the user with any querstions it needs to inorder to fill out the task.



Getting Started

simply click on the demo link in Terra or click on the pages link under this repository and vwala you have reached Kernl. Simply navagate between pages via the navagation bar at the top of the page.
